# Single Ease Question (SEQ), asked after each task

Ask straight after each task, even if the participant failed or was assisted.

> "Overall, how easy or difficult was this task?"

| 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|
| Very difficult | | | | | | Very easy |

* Scale per report Appendix C.3: **1 = very difficult, 7 = very easy**.
* Show the card; accept a spoken number. Do not explain what a number "should" be.
* Record in `Observations` column **SEQ (1-7)**. Leave blank if the participant declines (do not enter 0 or a guess).
* Report the mean of valid responses per task, with the number of valid responses (`Task Metrics` col R, S). The prototype study (Table 5) used the same 1-7 scale; compare only as a rough context, because the tasks differ.
